# Ar-Royyan — Modern Islamic Daily Companion

Aplikasi web Islami modern dan interaktif yang terpisah secara modular (HTML, CSS, JavaScript).

## Struktur File:
- `index.html`: Struktur utama aplikasi web.
- `style.css`: Gaya tampilan kustom, font, dan animasi.
- `script.js`: Seluruh logika aplikasi (Jam WIB, API Sholat, API Al-Qur'an & Player Murottal, Tasbih Digital, Arah Kiblat, & Jurnal Harian).

## Cara Menggunakan:
1. Ekstrak file ZIP ini.
2. Buka file `index.html` langsung di browser Anda atau jalankan melalui Live Server di VS Code.
3. Untuk deployment, Anda dapat mengunggah seluruh folder yang diekstrak ke GitHub Pages atau Netlify.
